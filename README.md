
Gestion RH Web

Application web de gestion des ressources humaines développée en ASP.NET/C# permettant de centraliser et simplifier la gestion des employés et des données RH.

Fonctionnalités
Gestion des employés
Ajout, modification et suppression des informations du personnel
Consultation de la liste des employés
Gestion des données via une base de données SQL
Interface web simple et intuitive
Technologies utilisées
ASP.NET
C#
HTML
CSS
JavaScript
SQL Server
Structure du projet
gestion-rh.web/
├── gestion-rh.BLL/
├── gestion-rh.web/
├── database.sql
└── gestion-rh.web.sln

Installation
Cloner le dépôt :
git clone https://github.com/Malaak50/gestion-rh.web.git

Ouvrir la solution :
gestion-rh.web.sln


Exécuter le script database.sql pour créer la base de données.

Configurer la chaîne de connexion dans le fichier de configuration.

Lancer le projet depuis Visual Studio.
